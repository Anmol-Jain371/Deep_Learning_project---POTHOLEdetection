RoadVision Phase13B Final Evidence Archive
=========================================

This archive contains all generated results, logs, corrected evaluation scripts, and supporting documentation for Phase 13B of the RoadVision project.

Included items:
- Evaluation run outputs (JSON, CSV, manifests, config snapshots, environment files) located under `runs/evaluation/phase13b/`.
- Permanent correction logs under `reports/PHASE13B_CORRECTIONS/logs/`.
- Corrected evaluation scripts from `experiments/phase13/`.
- This README describing run IDs, dataset roles, sample counts, evaluation settings, and metric definitions.
